# Week2 TNFA agent entry point

Start with `python3 scripts/workspace.py show` and overview.md. Select a campaign
and stage; load only its guide using `show --stage STAGE`. Read docs/CHALLENGE.md
before scientific work. Shared code and guide identities are pinned in
workflow.lock.json; update deliberately after validation.

Route: local hotspots → Foundry on Mimas → Boltz2 on Mimas → local scoring and
analysis. Choose constructs, trimer topology, hotspot numbering, seeds, checkpoints,
score methods and acceptance criteria explicitly. Historical EGFR examples under
reference/ must not become TNFA defaults. Preserve molecular source evidence,
chemistry, native identities and chain roles/copies.

The first campaign is not named. Create it when its objective is agreed. Use
drafts/ for editable inputs; changed inputs/settings create a new immutable
YYYY-MM-DD_label_NNN run with parent links. Use New York calendar dates and
explicit timestamp offsets. Keep progress/receipts separate from frozen inputs.
Read only the relevant common standard when producing figures or presentations.

Exact sequences need candidate records linking native FASTA identity/hash,
generation run, method/settings and parent candidates. Mutations/fusions create new
candidates. Record scores as source-located observations with method/version and
scientific scope; use `candidate trace` before ranking. Freeze cross-campaign
selection evidence and rationale. Missing generation/ranking evidence stays
explicit; computational scores and recorded metadata are not eligibility proof.
See docs/WORKSPACE.md for the commands. Submission requires researcher review.

Fleet resolves private machines, storage and environment locations. Transport
previews by default and --apply verifies hashes; it does not submit compute.
Validate native adapters, actual runtimes and inputs before the first scientific
run against new paths. Keep bulk artifacts canonical remotely and collect selected
verified copies. Registry/selection records are ignored: preserve them in recorded
backups with source artifacts. Never delete unique/unverified data.

Preserve Week1 and active paths. Avoid new symlinks; audit consumers before moves.
Alerts, Notion updates and automatic continuation are deferred. Ask at disruptive
phase boundaries.
